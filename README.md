Steps to run the automation script

Open folder "cp-alert-dashboard-automation-main" in Visual Studio Code
In the terminal inside Visual Studio Code enter pwd and verify that you are in "cp-alert-dashboard-automation-main"
Next run below commands
npm install
After the above installation completes, run below command to start the script.
npx tsx .\tests\auth.setup.ts    
Press Ctrl + C to close the script.
